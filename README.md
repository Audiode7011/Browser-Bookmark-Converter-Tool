## 🚀 Getting Started - Your First Conversion

Converting your bookmarks takes less than 60 seconds. Here's your step-by-step guide:

### Step 1: Export Your Bookmarks from Your Current Browser

Open your current browser (let's say Chrome for this example). Follow these steps:

- Click the three dots menu (⋮) in the top-right corner
- Go to "Bookmarks" → "Bookmark Manager"
- Click the three dots again in the bookmark manager
- Select "Export bookmarks"
- Save the file as `bookmarks.html` somewhere easy to find (like your Desktop)

### Step 2: Open Browser-Bookmark-Converter-Tool

Double-click the application you downloaded. A clean, simple window will appear.

### Step 3: Select Your Source Browser

In the first dropdown menu, choose the browser your bookmarks came from (Chrome, in this example).

### Step 4: Select Your Target Browser

In the second dropdown menu, choose the browser where you want your bookmarks to go (like Firefox or Edge).

### Step 5: Choose Your Bookmark File

Click the "Browse" or "Select File" button and find the `bookmarks.html` file you exported in Step 1.

### Step 6: Convert!

Click the "Convert" button. The tool will process your file and create a new converted file in the same folder, with a name like `bookmarks_converted.html`.

### Step 7: Import to Your New Browser

Open your target browser (Firefox, for example). Go to Bookmarks → Import and Backup → Import Bookmarks from HTML. Select the converted file you just created. Done! All your bookmarks are now in your new browser.
